## 📌 Projects

### Day 01: Student Academic Performance Predictor
- **Objective:** Predict students' final examination grade (`G3`, scale 0–20) based on social, demographic, and academic factors.
- **Dataset:** [UCI Student Performance (Math)](https://archive.ics.uci.edu/dataset/320/student+performance)
- **Key Techniques:**
  - Exploratory Data Analysis (EDA) & distribution histograms
  - Correlation heatmaps & outlier inspection
  - Binary & One-Hot Encoding for categorical features
  - Train/Test Split (80/20)
  - Linear Regression modeling
- **Results:**
  - **$R^2$ Score:** `0.724` (72.4% variance explained)
  - **Mean Absolute Error (MAE):** `1.65` marks
